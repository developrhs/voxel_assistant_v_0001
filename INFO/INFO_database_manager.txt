=================================( database_manager.py
Central de Operações de Dados (SQLite e JSON) do Assistente VOXEL

OBJETIVO PRINCIPAL:
Classe/módulo unificado responsável por:
1. Oferecer interface CRUD thread-safe para o banco SQLite (db_virtual_assistant.db).
2. Oferecer interface Read/Update atômica para o arquivo JSON (database_general.json).
3. Converter tipos e normalizar campos entre o padrão de banco e o padrão de aplicação.
4. Fornecer abstrações de alto nível para os módulos da aplicação (Ex: buscar usuário ativo, listar comandos, alterar configurações da IA).


================================= 1. ARQUITETURA E INICIALIZAÇÃO

AO INSTANCIAR A CLASSE DATABASEMANAGER:
PASSO 1.1 - Define os caminhos absolutos dos arquivos de persistência:
    - [db_path] = "D:/assistant/voxel/config/database/db/db_virtual_assistant.db"
    - [json_path] = "D:/assistant/voxel/config/database/database_general.json"

PASSO 1.2 - Inicializa mecanismo de trava/lock (Threading Lock):
    - Impede que concorrência de leitura/escrita corrompa o banco SQLite ou sobrescreva dados no JSON simultaneamente.

PASSO 1.3 - Verifica integridade inicial dos arquivos:
    - Se o SQLite não existir: executa a criação do schema das tabelas (tb_user, tb_comando, tb_condicao, tb_chat).
    - Se o JSON não existir: reconstrói com a estrutura padrão pré-definida.


================================= 2. OPERAÇÕES CRUD DO ARQUIVO GENERAL JSON

MÉTODO get_json_config(key_path=None):
PASSO 2.1 - Abre e lê o arquivo database_general.json de forma segura.
PASSO 2.2 - SE key_path for fornecido (ex: "configuracao_microfone.motor_reconhecimento"):
    - Navega na árvore JSON e retorna o valor específico.
PASSO 2.3 - SE key_path for None:
    - Retorna o dicionário completo das configurações.

MÉTODO update_json_config(key_path, new_value):
PASSO 2.4 - Carrega o dicionário do JSON em memória.
PASSO 2.5 - Localiza a chave e substitui o valor por `new_value`.
PASSO 2.6 - Atualiza a chave `_ultima_modificacao` com o timestamp atual ("YYYY-MM-DD HH:MM:SS").
PASSO 2.7 - Salva o arquivo JSON de forma atômica (escreve em arquivo temporário e substitui).


================================= 3. OPERAÇÕES CRUD DO BANCO SQLITE (db_virtual_assistant.db)

--- TABELA: tb_user ---
- get_active_user(): Busca o usuário onde `tb_user_status = 'ativo'` e retorna dicionário com os campos (nome, tratamento, username, etc).
- update_user(user_id, **kwargs): Atualiza informações do usuário.

--- TABELA: tb_comando ---
- get_command_by_key(keyword): Busca comando onde `tb_comando_chave = keyword` e `tb_comando_status = 'ativo'`.
- list_all_commands(): Retorna todos os comandos cadastrados para menus de ajuda.

--- TABELA: tb_condicao ---
- get_conditions_by_command_id(command_id): Retorna todas as condições vinculadas ao ID de um comando.
- get_condition_by_key(keyword): Busca condição direta por palavra-chave.

--- TABELA: tb_chat ---
- create_chat_session(user_id, title): Insere uma nova sessão de chat com data/hora de criação e retorna o `tb_chat_id`.
- update_chat_log(chat_id, log_text): Atualiza o histórico textual do chat e a data/hora de modificação.






================================= 4. Esqueleto didático do código em Python (database_manager.py)
import os
import json
import sqlite3
import threading
from datetime import datetime

class DatabaseManager:
    """
    Gerenciador unificado de persistência do assistente VOXEL.
    Abstrai o banco de dados SQLite e o arquivo de configurações JSON.
    """

    def __init__(
        self, 
        db_path=r"D:/assistant/voxel/config/database/db/db_virtual_assistant.db",
        json_path=r"D:/assistant/voxel/config/database/database_general.json"
    ):
        self.db_path = db_path
        self.json_path = json_path
        self._lock = threading.Lock()
        
        # Garante a existência dos diretórios
        os.makedirs(os.path.dirname(self.db_path), exist_ok=True)
        os.makedirs(os.path.dirname(self.json_path), exist_ok=True)

    # =========================================================================
    # SEÇÃO 1: NÚCLEO DE LEITURA E ESCRITA EM ARQUIVO JSON
    # =========================================================================

    def read_general_json(self) -> dict:
        """Lê o arquivo de configuração JSON completo."""
        with self._lock:
            if not os.path.exists(self.json_path):
                raise FileNotFoundError(f"Arquivo JSON não encontrado em: {self.json_path}")
            
            with open(self.json_path, 'r', encoding='utf-8') as file:
                return json.load(file)

    def get_json_value(self, key_path: str):
        """
        Recupera valor por caminho chave em ponto.
        Exemplo: get_json_value("configuracao_microfone.motor_reconhecimento") -> "azure"
        """
        data = self.read_general_json()
        keys = key_path.split(".")
        val = data
        for k in keys:
            if isinstance(val, dict) and k in val:
                val = val[k]
            else:
                return None
        return val

    def update_json_value(self, key_path: str, value) -> bool:
        """
        Atualiza um parâmetro no JSON usando notação de ponto.
        Exemplo: update_json_value("status_chatbot.selecionado", "Assistente")
        """
        with self._lock:
            data = self.read_general_json()
            keys = key_path.split(".")
            
            # Navega até o penúltimo nível
            curr = data
            for k in keys[:-1]:
                if k not in curr or not isinstance(curr[k], dict):
                    curr[k] = {}
                curr = curr[k]
            
            # Atualiza valor e timestamp
            curr[keys[-1]] = value
            data["_ultima_modificacao"] = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

            # Escrita atômica em disco
            temp_path = self.json_path + ".tmp"
            with open(temp_path, 'w', encoding='utf-8') as f:
                json.dump(data, f, indent=4, ensure_ascii=False)
            os.replace(temp_path, self.json_path)
            return True

    # =========================================================================
    # SEÇÃO 2: NÚCLEO DE OPERAÇÕES SQLITE (db_virtual_assistant.db)
    # =========================================================================

    def _get_connection(self):
        """Retorna uma nova conexão SQLite configurada para dicionários."""
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row  # Acesso aos campos por nome da coluna
        return conn

    # --- USUÁRIO (tb_user) ---

    def get_active_user(self) -> dict:
        """Obtém o usuário atualmente ativo no sistema."""
        with self._lock:
            conn = self._get_connection()
            cursor = conn.cursor()
            cursor.execute("SELECT * FROM tb_user WHERE tb_user_status = 'ativo' LIMIT 1")
            row = cursor.fetchone()
            conn.close()
            return dict(row) if row else {}

    # --- COMANDOS (tb_comando) ---

    def get_command_by_key(self, keyword: str) -> dict:
        """Busca um comando pela palavra-chave."""
        with self._lock:
            conn = self._get_connection()
            cursor = conn.cursor()
            cursor.execute(
                "SELECT * FROM tb_comando WHERE LOWER(tb_comando_chave) = LOWER(?) AND tb_comando_status = 'ativo'",
                (keyword,)
            )
            row = cursor.fetchone()
            conn.close()
            return dict(row) if row else {}

    # --- CONDIÇÕES (tb_condicao) ---

    def get_condition_by_key(self, keyword: str) -> dict:
        """Busca uma condição pela palavra-chave associada."""
        with self._lock:
            conn = self._get_connection()
            cursor = conn.cursor()
            cursor.execute(
                "SELECT * FROM tb_condicao WHERE LOWER(tb_condicao_chave) = LOWER(?) AND tb_condicao_status = 'ativo'",
                (keyword,)
            )
            row = cursor.fetchone()
            conn.close()
            return dict(row) if row else {}

    # --- HISTÓRICO DE CHAT (tb_chat) ---

    def create_chat_session(self, user_id: int, title: str = "Novo Chat") -> int:
        """Cria um novo registro na tabela tb_chat e retorna o ID gerado."""
        now = datetime.now()
        date_str = now.strftime("%Y-%m-%d")
        time_str = now.strftime("%H:%M:%S")

        with self._lock:
            conn = self._get_connection()
            cursor = conn.cursor()
            cursor.execute(
                """
                INSERT INTO tb_chat (tb_chat_tb_user_id, tb_chat_title, tb_chat_create_date, tb_chat_create_time, tb_chat_modify_date, tb_chat_modify_time, tb_chat_log_text)
                VALUES (?, ?, ?, ?, ?, ?, '')
                """,
                (user_id, title, date_str, time_str, date_str, time_str)
            )
            chat_id = cursor.lastrowid
            conn.commit()
            conn.close()
            return chat_id

    def append_chat_log(self, chat_id: int, new_log_text: str):
        """Atualiza a conversa e a data/hora de modificação do chat."""
        now = datetime.now()
        date_str = now.strftime("%Y-%m-%d")
        time_str = now.strftime("%H:%M:%S")

        with self._lock:
            conn = self._get_connection()
            cursor = conn.cursor()
            cursor.execute(
                """
                UPDATE tb_chat 
                SET tb_chat_log_text = tb_chat_log_text || ?, 
                    tb_chat_modify_date = ?, 
                    tb_chat_modify_time = ? 
                WHERE tb_chat_id = ?
                """,
                (new_log_text, date_str, time_str, chat_id)
            )
            conn.commit()
            conn.close()
