# config

Esta pasta pertence ao projeto VOXEL e contém os seguintes arquivos:

- `__init__.py`
- `config_assistant.py`
- `config_audio_input.py`
- `config_audio_output.py`
- `config_chatbot.py`
- `config_local_ai.py`
- `config_online_ai.py`
- `config_status.py`
- `database_manager.py`
- `config_controler.py` — leitura da configuração de controlos, perfis, mapeamentos e filtragem de entradas para comandos.
- `support/` — ferramentas controladas de diagnóstico e correção para áudio e IA.
- `support/support_manager.py` — testes de microfone, Texto em Voz, IA Local e IA Online, com resultados persistidos em `support_diagnostics` no `database_general.json`.
